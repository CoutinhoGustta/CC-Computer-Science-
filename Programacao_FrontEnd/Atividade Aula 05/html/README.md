
# Hélia — Criação de Personagens de RPG

## Sobre o Projeto

Hélia é um projeto acadêmico desenvolvido para a disciplina de Programação Front End do curso de Ciência da Computação.

O projeto consiste em um site com temática medieval e fantástica, criado para apresentar informações sobre um mundo de RPG e permitir que os usuários explorem diferentes opções para a criação de seus próprios personagens.

Através do site, é possível conhecer raças, classes, atributos, equipamentos, magias e outros elementos relacionados ao universo de RPG.

## Objetivo

O objetivo do projeto é desenvolver um site utilizando exclusivamente HTML, colocando em prática estruturação de páginas, navegação, formulários, multimídia e organização de conteúdo.

O projeto também busca proporcionar uma experiência de exploração de um universo medieval, permitindo que o usuário crie e consulte uma ficha de personagem.

## Sobre Hélia

Hélia é um universo de fantasia medieval que apresenta diferentes raças, classes, criaturas e possibilidades de aventura.

O mundo de Solmaris possui uma história própria, conflitos, mistérios e elementos mágicos que fazem parte da experiência do projeto.

O usuário pode explorar as informações disponíveis no site e utilizar o formulário de criação para desenvolver seu próprio personagem.

## Recursos HTML Utilizados

Durante o desenvolvimento, foram utilizados diversos recursos do HTML5, incluindo:

- Tags semânticas: `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
- Formulários com diferentes tipos de campos.
- Campo de seleção de arquivos (`input type="file"`).
- Campo de data (`input type="date"`).
- Campo de seleção de cores (`input type="color"`).
- Campos obrigatórios e placeholders.
- Elemento `datalist` para sugestões de preenchimento.
- Elementos de áudio e vídeo.
- Imagens com `figure` e `figcaption`.
- Elementos interativos `details` e `summary`.
- Tabelas, listas e textos formatados.

- Nome do jogador.
- Data de criação.
- Raça.
- Classe.
- Gênero.
- Alinhamento.
- Nível.
- Atributos.
- Perícias.
- Equipamentos.
